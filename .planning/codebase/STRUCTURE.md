## Directory Purposes

**`bin/`** — Orchestration. Single executable Python script (`penskillz`) exposing the full CLI surface (`sync`, `extract`, `install`, `update`, `list`, `status`, `add-source`, `remove-source`, `doctor`, `summarize`). Argparse routes each subcommand to a `cmd_*` handler (`bin/penskillz:486-507`).

**`lib/extractors/`** — Pluggable extractors. Each `.py` exposes `extract(*, src, dest, log) -> int`. Selected per-source via the `extractor:` field in `sources.yaml`; loaded dynamically by `_load_extractor()` (`bin/penskillz:248-259`).

**`lib/summary.py`** — Aggregation. Reads `dist/skills/index.json`, groups skills by source then category, emits the installable `penskillz-capabilities` meta-skill plus a human-readable `CAPABILITIES.md` at repo root (`lib/summary.py:161-189`).

**`sources/`** — Upstream clones. Gitignored as files, but the seven canonical sources are pinned as git submodules in `.gitmodules`. `git_sync()` will also clone non-submodule sources here (`bin/penskillz:220-235`).

**`dist/`** — Build output, fully gitignored (`.gitignore:2`). Wiped per-source on each `penskillz extract`. Layout: `dist/skills/<source>/<skill>/SKILL.md`, plus a top-level `dist/skills/index.json` manifest and `dist/skills/_meta/penskillz-capabilities/` for the summary skill.

**`docs/`** — Human documentation. `USAGE.md` for end-user workflows, `CONTRIBUTING.md` for extractor authoring.

**`.planning/codebase/`** — GSD command artifacts (ARCHITECTURE.md, STRUCTURE.md, etc.). Inputs to `/gsd:plan-phase` and `/gsd:execute-phase`.

## Key File Locations

**Entry Points:**
- `bin/penskillz`: CLI orchestrator (argparse dispatch at `bin/penskillz:486-507`).
- `install.sh`: bootstrap installer; clones repo → submodule init → sync/extract/install → PATH (`install.sh:44-78`).

**Configuration:**
- `sources.yaml`: authoritative registry consumed by `load_sources()` (`bin/penskillz:203-207`).
- `.gitmodules`: submodule pinning so `install.sh` can `git submodule update --init --depth 1`.
- `.gitignore`: excludes `.claude/`, `dist/`, `_test-install/`, `__pycache__/`, `*.pyc`, `.DS_Store`, `.venv/`.

**Core Logic:**
- `bin/penskillz:151-200`: `Source` dataclass — schema for one upstream.
- `bin/penskillz:248-259`: `_load_extractor()` — dynamic per-source dispatch.
- `bin/penskillz:262-280`: `extract_sources()` — orchestrates per-source extract → `write_index()` → `build_capabilities_summary()`.
- `bin/penskillz:342-365`: `install_for_agent()` — copy with `.penskillz-managed` marker.
- `lib/summary.py:80-102`: `_entries_by_source()` — category derived from each `SKILL.md`'s frontmatter.

**Testing:**
- No test directory present. `penskillz doctor` is the primary smoke-test (`bin/penskillz:470-481`).

## Naming Conventions

**Files:**
- Python modules: lower-case-hyphenated when they map to a `sources.yaml` `extractor:` value (e.g. `frontmatter-md.py`, `yaml-binary.py`). Plain snake_case for internal libs (`summary.py`).
- Markdown: UPPERCASE for top-level docs (`README.md`, `CAPABILITIES.md`); lowercase for nested docs (`docs/USAGE.md` is an exception following project convention).

**Directories:**
- Source slugs in `sources/` and `dist/skills/` are kebab-case and match `Source.name` exactly (used as primary key throughout).
- Skill output dirs under `dist/skills/<src>/` are kebab-case slugs `<prefix><slug>` produced by extractor `_slug()` helpers (e.g. `lib/extractors/strix.py:28-31`).

## Where to Add New Code

**New upstream source:**
- Register declaratively: `penskillz add-source <name> <url> [--ref --path --extractor --prefix]` (`bin/penskillz:439-450`) or edit `sources.yaml` directly.
- If pinning as a submodule: add an entry to `.gitmodules` with matching `path = sources/<name>`.
- If the existing extractors fit (frontmatter-md, directory-md, yaml-binary), no code changes needed.

**New extractor:**
- Create `lib/extractors/<name>.py` exporting `def extract(*, src, dest, log) -> int`.
- Read upstream files from `src.skills_root()`; write `dest/<skill>/SKILL.md` with frontmatter (`name`, `description`, `metadata.source`, `metadata.category`).
- Reference from `sources.yaml` via `extractor: <name>`.
- Existing extractors are the templates: simplest is `lib/extractors/frontmatter-md.py` (75 LOC); most complex is `lib/extractors/yaml-binary.py` (260 LOC).

**New CLI subcommand:**
- Add a `cmd_<name>(args, log)` handler in `bin/penskillz`.
- Register in `build_parser()` (`bin/penskillz:486-507`).

**New agent install target:**
- Add an entry to `AGENT_TARGETS` at `bin/penskillz:46-51` (key = agent name, value = `(env_var, default_path)`).

**Docs and planning:**
- User docs: `docs/`.
- GSD planning / codebase analysis: `.planning/codebase/`.
- Regenerated capabilities snapshot: `CAPABILITIES.md` (do not hand-edit — overwritten by `lib/summary.py:186-187`).

## Special Directories

**`sources/`:**
- Purpose: upstream git clones.
- Generated: yes — by `git_sync()` or `git submodule update`.
- Committed: only the submodule SHA refs (via `.gitmodules`); contents are gitignored otherwise.

**`dist/`:**
- Purpose: canonical extractor output staged for install.
- Generated: yes — by `penskillz extract`.
- Committed: no (`.gitignore:2`).

**`.claude/`:**
- Purpose: local working copy of skills for the project itself.
- Committed: no (`.gitignore:1`).

**`_test-install/`:**
- Purpose: throwaway install target for testing `install.sh`.
- Committed: no (`.gitignore:3`).
